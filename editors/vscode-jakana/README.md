# Jakana Language Support for VS Code

This local extension adds `.jk` file recognition, syntax highlighting, Jakana file icons, comments, brackets, and quote auto-closing for Jakana.

## Install for development

1. Open the `editors/vscode-jakana` folder in a separate VS Code window.
2. Press `F5` to launch an Extension Development Host.
3. Open a `.jk` file in that new window.

The Jakana syntax highlighting will be active there.

To use the Jakana file icon in your normal VS Code window, run **Preferences: File Icon Theme** and select **Jakana File Icons**.

For a permanent installation, package this folder as a VSIX and install it from **Extensions: Install from VSIX...**.
